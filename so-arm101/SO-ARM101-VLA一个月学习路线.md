# SO-ARM101 + VLA 一个月学习路线

## 总目标

跟随 SO-ARM101 / LeRobot 教程完成一个真实项目：

> 让机械臂识别桌面上的一个物体，将它从起始区域抓取并放到目标区域。

建议任务：抓取一个红色方块，并放到左侧托盘。

一个月内的完成标准：

- SO-ARM101 能稳定完成主从遥操作。
- 能独立完成校准、摄像头检查和数据采集。
- 能理解 LeRobot 数据集中的 observation、action 和 episode。
- 完成一个 20～50 条示范数据的数据集。
- 完成一次云 GPU 训练或策略微调。
- 模型能在固定场景下让真实机械臂完成抓取任务。
- 能分析至少 3 种失败原因，并完成一次数据或参数改进。

## 学习方法

采用“边做边学”的方式：

```text
跟着文档完成一个步骤
→ 理解这个步骤背后的原理
→ 实际运行并记录输出
→ 遇到不懂的概念及时补基础
→ 继续下一个步骤
```

每次遇到问题时记录：

```text
当前阶段：
正在执行：
终端输出或报错：
我不理解的概念：
下一步：
```

## 第 1 周：环境、硬件和遥操作

### 实操目标

- 安装 LeRobot 和 Feetech 依赖。
- 查找主臂、从臂的 USB 端口。
- 设置舵机 ID。
- 完成主臂和从臂校准。
- 运行无视觉遥操作。
- 运行带摄像头遥操作。

### 需要理解的基础

- Leader：人工示教输入。
- Follower：执行动作的机械臂。
- 舵机 ID：总线中每个电机的唯一地址。
- 校准：建立关节读数与实际机械位置之间的对应关系。
- Observation：机器人状态和摄像头图像等观测。
- Action：发送给机械臂的动作指令。
- Control loop：读取观测、计算动作、执行动作的循环。

### 本周验收

- 可以用主臂控制从臂完成移动和夹爪开合。
- 可以解释主臂移动后，从臂如何获得动作指令。
- 可以保存端口、设备 ID 和校准文件位置。

## 第 2 周：数据采集和数据理解

### 实操目标

- 固定摄像头、桌面和任务区域。
- 先录制 5 条数据检查流程。
- 再录制 20～50 条正式示范数据。
- 查看数据是否包含图像、关节状态、动作和时间信息。
- 删除明显失败或不完整的 episode。

### 数据采集原则

- 每条示范都从相近的初始状态开始。
- 任务动作完整，包含接近、抓取、移动和放置。
- 保持光照、背景和摄像头位置稳定。
- 在保持任务不变的情况下，适度改变物体位置和角度。
- 训练和推理使用相同的摄像头配置。

### 需要理解的基础

- Episode：一次完整任务过程。
- 时间序列：图像、状态和动作按时间排列。
- 数据集：多次示范组成的训练材料。
- 训练集、验证集和测试集。
- 数据质量比单纯增加数据数量更重要。

### 本周验收

- 能打开并检查一条 episode。
- 能指出图像、关节状态和 action 分别在哪里。
- 能判断一条数据为什么可能不适合训练。

## 第 3 周：云 GPU 训练

### 实操目标

- 将数据集上传到云 GPU。
- 上传或安装对应版本的 LeRobot 工程。
- 先运行一个已有策略的推理示例。
- 再训练一个简单的行为克隆策略。
- 保存并检查 checkpoint。

### 先理解的模型流程

```text
示范数据
→ 模型读取图像和机器人状态
→ 模型学习示范动作
→ 输入新的观测
→ 输出动作序列
→ 机械臂执行
```

### 需要理解的基础

- Tensor：模型处理的数字数组。
- Batch：一次送入模型的一组样本。
- Loss：预测动作与示范动作之间的误差。
- Checkpoint：训练过程中的模型保存点。
- Inference：使用已经训练好的模型产生动作。
- Overfitting：模型记住训练场景，却不能适应新位置。

### 算法学习顺序

1. 行为克隆的基本思想。
2. ACT 或其他简单策略的输入输出。
3. Diffusion Policy。
4. SmolVLA、Pi0 或教程指定的 VLA 模型。

先把项目跑通，再比较不同模型名称和结构。

## 第 4 周：真实机械臂部署和改进

### 实操目标

按以下顺序测试：

1. 在训练集相似场景中测试。
2. 只改变物体位置。
3. 改变物体角度。
4. 改变光照。
5. 更换相似物体。
6. 记录失败原因。
7. 采集针对性数据并重新训练。

### 失败分析表

| 现象 | 可能原因 | 检查方向 |
| --- | --- | --- |
| 完全不动 | 端口、设备 ID、模型路径或控制进程错误 | 检查连接和终端日志 |
| 动作方向错误 | 校准、关节映射或坐标方向问题 | 检查主从臂校准和关节顺序 |
| 能靠近但抓不准 | 视觉视角、相机位置或数据覆盖不足 | 检查图像和物体位置变化 |
| 抓取成功率不稳定 | 示范差异大或初始状态不一致 | 增加稳定、完整的示范 |
| 训练集成功，换位置失败 | 过拟合或数据分布太窄 | 增加位置和角度变化 |

### 本周验收

- 模型能在固定场景下自主完成任务。
- 能解释一次失败是视觉、标定、控制还是数据问题。
- 完成至少一轮针对失败原因的改进。

## 需要逐步学习的基础知识

### 机器人学

- 关节角度和关节限位。
- 坐标系和坐标变换。
- 正运动学：关节角度 → 末端位姿。
- 逆运动学：末端目标 → 关节角度。
- 末端执行器和夹爪。

### 视觉

- 图像坐标与机器人坐标。
- 固定相机与手眼相机。
- 摄像头视野、标定和相机位置。
- 简单目标检测和颜色分割。

### 深度学习

- 张量、数据集、批次。
- 训练、验证和推理。
- Loss、梯度和 checkpoint。
- 过拟合与泛化。

### 模仿学习和 VLA

```text
人类示范
→ 记录 observation/action
→ 学习 observation 到 action 的映射
→ 在新场景中预测动作
```

本项目中的 VLA 可以先理解为：根据视觉观测和任务信息预测机器人动作的策略模型。先掌握视觉到动作的闭环，再深入语言条件、多任务泛化和大模型结构。
