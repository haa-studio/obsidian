# 三相两电平逆变器零序注入原理（校核版）

## 结论

原笔记给出的 3 V 数值例子是正确的：给三相端子参考同时加上同一个偏移量，只会改变端子对 DC- 的绝对电位，不改变线电压，也不改变理想情况下电机绕组的相电压。

需要特别修正三点：

1. `VN=(VU+VV+VW)/3` 是理想星点悬浮模型；实际还会受绕组不对称、寄生电容和测量带宽影响。
2. 不能简单说“转矩由线电压直接决定”。转矩主要由磁链和电流决定；线电压通过电机电阻、电感和反电动势方程影响电流。
3. `78.5%` 和 `90.7%` 通常是相对于六步方波基波的归一化利用率，不是“基波电压占 Vdc 的百分比”。

## 一、电压定义

| 电压 | 参考点 | 说明 |
|---|---|---|
| `VU/VV/VW` | 直流母线负极 DC- | 桥臂端子电压，理想两电平只能在 `0~Vdc` 之间 |
| `UUN/UVN/UWN` | 电机浮动中性点 N | `UUN=VU-VN`，可以为正或负 |
| `UUV/UVW/UWU` | 另一相端子 | `UUV=VU-VV` 等，与 N 无关 |

直流电容中点（若硬件引出）与电机浮动中性点不是同一个节点。电容中点理想约为 `Vdc/2`，但电机星点 N 会随三相端子电压和开关状态变化。

> [!warning] 适用条件
> `VN=(VU+VV+VW)/3` 适用于理想三相、星点悬浮、无中性线电流并忽略寄生电容的模型。实际系统需要考虑绕组不对称、共模电容和开关瞬态。

### 三种关键电压

1. **端子对 DC- 电压**

   `VU`、`VV`、`VW` 是逆变器输出端相对于直流母线负极 DC- 的电压。理想两电平桥臂只能在 `0` 和 `Vdc` 之间切换，因此平均值也只能落在 `0~Vdc`。

2. **电机相电压**

   ```text
   UUN = VU - VN
   UVN = VV - VN
   UWN = VW - VN
   ```

   它们是绕组真正承受的电压，可以为正或为负。

3. **线电压**

   ```text
   UUV = VU - VV
   UVW = VV - VW
   UWU = VW - VU
   ```

   线电压与电机浮动中性点无关，因为公共的 `VN` 会相互抵消。

## 二、为什么需要零序注入

设：

- `Vdc = 3 V`
- 直流母线数学中点为 `1.5 V`
- 目标绕组相电压瞬时值为：`UUN=+1.732 V`，`UVN=UWN=-0.866 V`
- 相电压峰值为 `1.732 V`，对应线电压峰值为 `sqrt(3)*1.732=3 V`

### 情况 1：不注入零序

以 1.5 V 的直流中点为参考，直接生成：

```text
U 相参考电压 = +1.732 V
V 相参考电压 = -0.866 V
W 相参考电压 = -0.866 V
```

换成相对于 DC- 的端子电压：

```text
VU = 1.5 + 1.732 = 3.232 V
VV = 1.5 - 0.866 = 0.634 V
VW = 1.5 - 0.866 = 0.634 V
```

`VU=3.232 V > Vdc`，超出了两电平桥臂的可实现范围，调制器只能饱和或削顶。

普通正弦 PWM 在线性调制区的相电压峰值上限是：

```text
Vphase,peak,max = Vdc / 2
```

### 情况 2：注入零序偏移

给三相参考同时加入同一个共模偏移：

```text
u0 = -0.232 V
```

新的端子对 DC- 电压为：

```text
VU' = 3.232 - 0.232 = 3.000 V
VV' = 0.634 - 0.232 = 0.402 V
VW' = 0.634 - 0.232 = 0.402 V
```

三相都落在 `0~3 V` 内。

理想浮动中性点为：

```text
VN' = (3.000 + 0.402 + 0.402) / 3 = 1.268 V
```

重新计算得到：

```text
UUN' = 3.000 - 1.268 = +1.732 V
UVN' = 0.402 - 1.268 = -0.866 V
UWN' = 0.402 - 1.268 = -0.866 V
```

所以电机相电压和线电压没有改变，所有桥臂端子均落在 `0~Vdc` 内。

## 三、通用证明：共模偏移不改变电机电压

令：

```text
VU' = VU + u0
VV' = VV + u0
VW' = VW + u0
VN' = (VU' + VV' + VW') / 3 = VN + u0
UUN' = VU' - VN' = UUN
UUV' = VU' - VV' = UUV
```

`u0` 可以是常数，也可以随时间变化；同时加到三相参考上的分量就是零序/共模分量。第三谐波注入就是一种随时间变化的零序分量。

## 四、零序注入带来的电压利用率提升

在线性调制区：

| 调制方式 | 最大基波相电压峰值 | 最大基波线电压峰值 | 最大基波线电压 RMS |
|---|---:|---:|---:|
| 普通 SPWM | `Vdc/2` | `0.866Vdc` | `0.612Vdc` |
| 零序注入 SPWM / SVPWM | `Vdc/sqrt(3)=0.577Vdc` | `Vdc` | `0.707Vdc` |

线性区的最大基波电压提高为：

```text
(1/sqrt(3)) / (1/2) = 1.1547
```

也就是约 **15.47%**。

### 78.5% 和 90.7% 的正确含义

工程资料中常见的：

- 普通 SPWM：约 `78.5%`
- SVPWM/三次谐波注入：约 `90.7%`

通常是把线性调制区的基波线电压 RMS 归一化到六步方波基波 RMS 后得到的指标，不是“输出电压等于母线电压的百分比”。因此必须注明归一化基准。

## 五、SVPWM 与三次谐波注入

| 对比维度 | SVPWM | 三次谐波注入 SPWM |
|---|---|---|
| 核心方法 | α-β 电压矢量、扇区和 `T0/T1/T2` | 三相正弦参考叠加零序三次谐波 |
| 零序来源 | 由零矢量时间和开关序列自然形成 | 显式加入三次谐波；常见幅值为基波峰值的 `1/6` |
| 线性区电压能力 | 与三次谐波注入数学等效 | 与 SVPWM 数学等效 |
| 实现特点 | 可选七段、五段及不同零矢量分配 | 逻辑直观，但仍需限幅和载波比较 |
| 开关损耗 | 可通过序列设计优化 | 取决于载波和钳位策略 |

三次谐波属于零序，因此在线电压中抵消：

```text
sin(3θ) - sin(3θ) = 0
```

但它会改变每个桥臂对 DC- 的极点电压和占空比范围。

## 六、常见误区

1. **电机浮动中性点恒等于 `Vdc/2`**：错误。只有某些对称平均状态下才可能恰好如此；开关状态变化时会浮动。
2. **电机相电压不能为负**：错误。不能为负的是桥臂端子对 DC- 电压；相对于浮动 N 的绕组电压可以为负。
3. **零序注入会改变电机转矩**：理想平均模型下，共模偏移不改变线电压和相电压，因此不直接改变转矩；但实际寄生电容、共模电流、死区和采样误差可能带来间接影响。
4. **普通 SPWM 与 SVPWM 的电压利用率一样**：错误。在线性区，SVPWM/零序注入比普通 SPWM 的最大基波电压高约 15.47%。
5. **电机中性点接到了直流母线中点**：通常错误。电机星点一般悬浮，直流电容中点是另一处节点。

## 八、实际系统限制与测量建议

- 死区、器件压降、采样延迟、PWM 更新时刻、过调制和母线电容不平衡会使实际波形偏离理想公式。
- 共模电压仍可能引起寄生电容电流、轴承电流和 EMI；“不改变理想线电压”不等于“没有共模影响”。
- 测量浮动电机端子时不要使用普通单端示波器地夹，应用额定共模电压足够的差分探头。
- 测量时应分别观察桥臂对 DC- 的极点电压、线电压和母线电压。
