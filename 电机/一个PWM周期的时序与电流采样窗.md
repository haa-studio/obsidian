# 一个 PWM 周期的时序与电流采样窗（推导版）

## 结论

1. 中断点在**三角波顶点**，那里是三相下桥**唯一同时导通**的时刻，也是相电流**恰好等于平均值**的时刻。
2. 采样窗只有 **3.57 µs**（由 `TCMP_MAX=3600` 决定），**比整个 ADC 序列 5.76 µs 还短**。能工作是因为**每一路只占用「自己那相」的下桥导通窗**，不是共用一个 5.76 µs 的大窗。
3. 最紧的是 **C 相**：余量只有 **47 个计数 = 0.28 µs**。这就是 `TCMP_MAX = 3600` 的物理来源。
4. `TCMP_MAX` 不是"限幅好看"，而是在**保证反馈回路不断线**。越过它会引发积分饱和自锁。

---

## 一、周期与时钟（五个输入常数）

| 常数 | 值 | 出处 |
|---|---|---|
| 定时器时钟 | 168 MHz | `PLLN=168, PLLP=2` ⇒ HCLK=168 MHz |
| `ARR` | 4199 | `htim1.Init.Period` |
| **1 个计数的时间** | **1/168 MHz = 5.952 ns** | 中心对齐每拍 count ±1 |
| `PCLK2` | 84 MHz | `APB2CLKDivider = RCC_HCLK_DIV2` |
| ADC 预分频 | /4 ⇒ **ADCCLK = 21 MHz** | `ADC_CLOCK_SYNC_PCLK_DIV4` |
| **1 个 ADC 时钟** | **1/21 MHz = 47.62 ns** | |

中心对齐周期 = `2 × 4199` 计数 = 8398 / 168 MHz = **49.99 µs**。

## 二、中断为什么在顶点

`CCR4 = ARR`（在 `Motor_Hardware_Init` 里覆盖了 CubeMX 的 4195）。

中心对齐下 CNT 一个周期走 `0 → 4199 → 0`：

- `CCR4 = 4195` 时，CNT 每周期**两次**经过它（上行、下行），两跳只差 `2×4 = 8` 个计数 = **47.6 ns**。第二次落在 ISR 入口内，被 `HAL_TIM_IRQHandler` 的清标志顺带清掉 ⇒ 实测 20 kHz，**但这是竞态**（依赖"中断延迟 > 47.6 ns"）。
- `CCR4 = ARR` 时，CNT 每周期**只在顶点经过一次** ⇒ 几何上恰好一次命中，与延迟无关。

> [!warning] 为什么这个细节重要
> 若变成 40 kHz 而 `Ki_ts` 仍按 50 µs 算，等效积分量翻倍，电流环阻尼从 1.0 掉到 0.71。

## 三、ISR 内部的执行顺序与耗时

| 段 | 内容 | 耗时 | 数据来源 |
|---|---|---|---|
| ① | 编码器 SPI 阻塞读 + 角度换算 | 9.85 µs | L0 实测 |
| ② | 电流重构（减零偏→扣零序→Clarke→Park） | 2.8 µs | 实测 465 拍 |
| ③ | SVPWM 计算 + 写 CCR | 4.1 µs | L0 实测 |
| 合计 | | **约 17 µs** | 推算，**未整体复测** |

> [!note] ADC 与编码器是并行的
> ISR 第一行发 `SWSTART` 后，ADC 序列由 DMA 在后台搬运（5.76 µs），**同时** CPU 在阻塞读编码器 SPI（9.85 µs）。
> 所以总耗时不是 `5.76+9.85+2.8+4.1 = 22.5 µs`，而是约 17 µs。

## 四、为什么必须在顶点采样

### 4.1 PWM1 的比较规则

```text
输出高  ⇔  CNT < CCR
```

注意是**小于**——高电平出现在 CNT **小**的地方，也就是**谷底附近**，不是顶点。

CCR=2099（50%）时，高电平区间以谷底为中心，前后各 6.25 µs：

```text
CNT  4199 ┤        ╱╲
          │       ╱  ╲
     2099 ┤──────╱────╲──────   ← 高低电平分界
          │  ████      ████     ← 高边导通
        0 └────────────────
          谷底   顶点   谷底
```

三相 CCR 不同、矩形宽度不同，但**都对称跨在谷底上**。

**推论：顶点处 CNT=4199，三相全部 `CNT > CCR` ⇒ 高边全关、下桥全开。**

### 4.2 为什么必须下桥导通才能测

分流电阻 7 mΩ 接在**下桥 MOSFET 源极与 GND 之间**：

```text
      VM
       │
    ┌──┴──┐ 高边
    ├─────┴────── 相线（去电机）
    ┌┴┐  低边
    └┬┘
     ├──[ 7 mΩ ]── GND   ← 电流走这条才有压差
     └──→ SP/SN 去 CSA
```

- 下桥导通 → 相电流经低边 → 流过 7 mΩ → CSA 测得到
- 上桥导通 → 电流走上面 → 低边无电流 → 分流电阻上 0

### 4.3 为什么顶点处的电流等于平均值（本质原因）

三相电流是三角波纹波：上桥通时上升、下桥通时下降。**对称三角波在"上升段中点"和"下降段中点"都恰好等于平均值。**

顶点位于下桥导通区间的**正中间**：

```text
相电流
   ╱╲        ╱╲
  ╱  ╲      ╱  ╲
 ╱    ╲    ╱    ╲
───────●───────────●────  平均值
       ↑         ↑
     顶点采样
```

**所以在顶点采样 = 采到平均电流 = 纹波误差为零。** 若在别处采，纹波会直接变成电流环噪声；本机纹波约 14.7 mA，对 0.2 A 量程已是 7%。

## 五、采样窗有多宽，逐路怎么算

### 5.1 每路转换时间

F4 的 12 位转换固定 **12 个 ADCCLK**（SAR 逐次逼近），加采样时间：

```text
CH0/1/2：(15 + 12) = 27 ADCCLK = 1285.7 ns ≈ 1.286 µs
CH3    ：(28 + 12) = 40 ADCCLK = 1904.8 ns ≈ 1.905 µs
总量   ：27×3 + 40 = 121 ADCCLK = 5.762 µs
```

### 5.2 时间片与采样相结束时刻

**关键：只有"采样相"要求下桥导通。** 采样开关在转换相已经断开，输入不再影响结果。

| 通道 | 时间片 | 采样相结束 |
|---|---|---|
| CH0 | 0 → 1.286 µs | **0.714 µs** |
| CH1 | 1.286 → 2.571 | **2.000 µs** |
| CH2 | 2.571 → 3.857 | **3.286 µs** |
| CH3 | 3.857 → 5.762 | 5.190 µs |

### 5.3 换算成当时的 CNT

```text
CNT = 4199 − t / 5.952ns      (CNT 从顶点的 4199 单调下降)
```

| 通道 | t | t/5.952ns | CNT |
|---|---|---|---|
| CH0 | 714 ns | 120 | **4079** |
| CH1 | 2000 ns | 336 | **3863** |
| CH2 | 3286 ns | 552 | **3647** |
| CH3 | 5190 ns | 872 | 3327 |

### 5.4 变成对 Tcmp 的约束

高边导通是 `CNT < CCR`，所以**下桥导通是 `CNT > CCR`**。要在采样相结束时下桥仍通：

```text
Tcmp < CNT(采样相结束时)
```

| 通道 | 约束 | 3600 时余量（计数） | 折算时间 |
|---|---|---|---|
| CH0 | ≤ 4079 | 479 | **2.85 µs** |
| CH1 | ≤ 3863 | 263 | **1.57 µs** |
| CH2 | ≤ **3647** | **47** | **0.28 µs** ← 最紧 |
| CH3 | 无约束 | — | VBUS 是直流分压，与开关无关 |

## 六、两个容易踩的坑

1. **用整段时间片而不是采样相**：若用 CH2 的整段终点 3.857 µs，会算成 `4199 − 648 = 3551`，结论变成"TCMP_MAX 只能到 3551"，**保守 2.6%**，白丢电压利用率。
2. **忘记 CNT 从 4199 往下数**：若错当成从 0 往上数，会算成 552，结论完全相反。判据是**中断在顶点触发**。

## 七、越过窗口的后果：积分饱和自锁

```text
该相下桥已关断 → 分流电阻无电流 → ADC 读到 0
      ↓
PI 认为"电流不够" → 继续加大 Vd
      ↓
占空比更大 → 窗口更窄 → 还是读到 0
      ↓
积分饱和 → 电压打满 → 实际电流远超预期 → 过流
```

所以 `FocAlgorithm.c` 里有**两条不同性质**的边界：

| 边界 | 值 | 性质 |
|---|---|---|
| `TPWM` | 4199 | **数学合法性**：超过它该相整周期不翻转 |
| `TCMP_MAX` | 3600 | **测量可行性**：超过它反馈断线 |

## 八、新占空比什么时候生效

`CCMR1 = CCMR2 = 0x6868` ⇒ `OC1PE/OC2PE/OC3PE = 1`，**CCR 预装载已开启**（由 `HAL_TIM_PWM_Start` 里的 `ENABLE_OCxPRELOAD` 置位）。

⇒ ISR 在 41.75 µs 写完 CCR，新占空比要等**下一个更新事件**才生效，**每个周期的脉冲保持对称**。

## 九、还有 1.3% 的余量，但不建议动

`TCMP_MAX` 理论上可到 **3647**，比 3600 多 1.3% 调制度。但 47 个计数 = 0.28 µs，已与开关噪声、中断抖动同量级。

另一种压榨方式是**调整 rank 顺序**（把占空比最大的相排到 CH0，它有 4079 的余量），但需要每拍动态改 `SQR3`，得不偿失。
