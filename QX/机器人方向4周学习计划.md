# 机器人方向 4 周学习计划

适用资料：`QXS320F280049RevB` 开发板、芯片数据手册、技术参考手册、开发板原理图、`driverlib` API、`f280049revb_evb_examples` 例程。

目标不是“学完芯片”，而是 4 周后能拿这块板子做出一个机器人行业能认可的嵌入式控制小项目：采样、PWM、编码器、CAN/串口通讯、简单闭环控制。

## 今天开始干什么

今天只做 4 件事：

1. 安装并打开 `QX-IDE`
   - 按例程仓库的 `f280049revb_evb_examples-master/f280049revb_evb_examples-master/README.md` 操作。

2. 导入例程工程
   - 导入 `F280049RevB_examples_core0`。
   - 暂时不要管 `core1`。
   - 暂时不要改 `bootloader`。

3. 编译一个最简单的例程
   - 优先找 `gpio`、`led`、`cputimer`、`sci_send_recv_by_interrupt` 这类例程。
   - 如果不确定选哪个，就先选 `sci_send_recv_by_interrupt`，因为串口调试是后面所有项目的基础。

4. 建一个学习记录文档

```text
日期：
今天跑通了什么：
改了哪些代码：
遇到的问题：
明天要做什么：
```

今天的最低完成标准：能成功编译一个例程。

今天的理想完成标准：能把程序烧进板子，并看到 LED、串口、调试现象之一。

## 第 1 周：把板子跑起来，建立嵌入式基本手感

目标：能独立完成“编译、下载、运行、调试、串口输出”。

重点资料：

- `f280049revb_evb_examples-master/f280049revb_evb_examples-master/README.md`
- `QX-IDE 用户手册`
- `QXS320F280049RevB开发板SCH_2025-11-05.pdf`
- `driverlib` 里的 GPIO、CPUTimer、SCI 章节

### 第 1 天：环境搭建

完成 QX-IDE 安装、例程导入、能编译一个 core0 单核例程。

### 第 2 天：GPIO

跑 GPIO/LED 相关例程。

要搞清楚：

- GPIO 初始化在哪里
- 引脚复用怎么配
- 高低电平怎么输出
- 开发板原理图里 LED 接在哪个引脚

### 第 3 天：CPU Timer

跑定时器例程。

目标：让 LED 每 500ms 翻转一次。

要理解：

- 定时器周期怎么设置
- 中断函数在哪里
- 中断标志怎么清除

### 第 4 天：SCI 串口

跑 `sci_send_recv_by_interrupt` 或类似例程。

目标：电脑串口助手能收到板子发来的字符串。

### 第 5 天：串口命令控制 LED

把 GPIO + SCI 合起来。

目标：

- 电脑发送 `1`，LED 亮
- 电脑发送 `0`，LED 灭

### 第 6 天：整理代码

把这周跑通的例程整理成一个小项目：`uart_led_control`。

### 第 7 天：复盘

写一页总结：

- QX-IDE 怎么导入工程
- 怎么选例程编译
- GPIO、Timer、SCI 的初始化流程
- 中断函数怎么写

第 1 周合格标准：不用别人手把手带，自己编译下载一个例程，并通过串口控制开发板。

## 第 2 周：进入机器人控制核心外设 ADC + EPWM

目标：理解机器人控制里最核心的一件事：定时产生 PWM，同时同步采样 ADC。

重点资料：

- `driverlib API` 的 ADC 章节
- `driverlib API` 的 EPWM 章节
- 芯片技术参考手册里的 ADC、EPWM
- 开发板原理图里的 ADC 输入和 PWM 引脚

### 第 8 天：ADC 基础例程

跑 ADC 采样例程。

目标：采一个电压值，通过串口打印出来。

重点看这些 API：

- `ADC_setPrescaler`
- `ADC_enableConverter`
- `ADC_setupSOC`
- `ADC_setInterruptSource`
- `ADC_readResult`

### 第 9 天：ADC + 串口打印

把 ADC 采样值转成可读格式，通过 SCI 输出。

目标：串口看到类似：

```text
adc = 2048
voltage = 1.65V
```

### 第 10 天：EPWM 基础例程

跑 EPWM 输出例程。

目标：用示波器、逻辑分析仪或板上连接方式确认 PWM 波形。

如果没有示波器，也先把代码跑通，并学会怎么算频率和占空比。

要重点理解：

- PWM 频率怎么由时钟和周期寄存器决定
- 占空比怎么改
- 上升沿、下降沿动作怎么配

### 第 11 天：串口调节 PWM 占空比

目标：

- 串口发送 `duty 20`，占空比变 20%
- 串口发送 `duty 80`，占空比变 80%

这一步非常重要，因为机器人控制里的“调参”本质上就是这个能力。

### 第 12 天：EPWM 触发 ADC

目标：让 ADC 不是乱采，而是由 PWM 周期触发采样。

这是电机控制、FOC、伺服控制的基础。

### 第 13 天：整理成项目

项目名：`pwm_adc_monitor`。

功能：

- PWM 固定频率输出
- ADC 定时采样
- 串口打印采样值
- 串口可调 PWM 占空比

### 第 14 天：复盘

写清楚：

- ADC 的 SOC 是什么
- EPWM 为什么适合触发 ADC
- PWM 频率和占空比怎么算
- 为什么机器人控制要固定周期采样

第 2 周合格标准：能写出一个“PWM 输出 + ADC 采样 + 串口监控”的小工程。

## 第 3 周：编码器 EQEP + CAN 通讯

目标：接近真实机器人控制器：读位置/速度，并通过总线通讯。

重点资料：

- `driverlib API` 的 EQEP 章节
- `driverlib API` 的 CAN / CAN-FD 章节
- 开发板原理图里的 EQEP、CAN 引脚
- 技术参考手册相关章节

### 第 15 天：EQEP 例程

跑编码器相关例程。

如果没有编码器，可以先读代码，把接口和寄存器流程搞清楚；有编码器就实际接上。

要理解：

- A/B 相编码器是什么
- 位置计数怎么读
- 方向怎么判断
- 速度怎么估算

### 第 16 天：编码器位置串口输出

目标：串口周期打印：

```text
pos = 12345
dir = forward
```

### 第 17 天：速度计算

目标：每隔固定时间读取位置差，计算速度。

这就是速度环的输入。

### 第 18 天：CAN 基础例程

跑 CAN 发送/接收例程。

要理解：

- CAN ID
- 数据帧
- 波特率
- 发送邮箱、接收过滤
- 中断接收

### 第 19 天：串口转 CAN

目标：

- 电脑串口输入一组数据
- 板子通过 CAN 发出去

如果没有第二块板子或 CAN 工具，先完成代码逻辑和编译。之后找同事借 CAN 分析仪验证。

### 第 20 天：CAN 接收控制 PWM

目标：

- 收到 CAN 指令后改变 PWM 占空比
- 这就接近实际电机控制器的控制接口

### 第 21 天：复盘

写清楚：

- EQEP 读到的是什么
- 速度怎么算
- CAN 一帧数据怎么组织
- 为什么机器人行业大量使用 CAN

第 3 周合格标准：能说清楚并实现“读取编码器 + 通过 CAN/串口传输控制参数”。

## 第 4 周：做一个能展示的机器人控制小项目

目标：做一个可放进简历或面试讲述的小项目。

建议项目名：`Mini Motor Control Board Demo`。

如果有电机和驱动硬件，做真实电机速度控制。

如果没有电机，就做“模拟闭环控制框架”：PWM 输出、ADC 采样、编码器接口、CAN/串口调参都具备。

功能目标：

1. 系统初始化
   - 包括时钟、GPIO、SCI、ADC、EPWM、EQEP、CAN。

2. 固定周期控制任务
   - 用 Timer 或 EPWM 中断触发，例如 1kHz 或 10kHz。

3. 采样输入
   - ADC 读取模拟量，EQEP 读取位置。

4. 控制输出
   - 根据目标值调节 PWM 占空比。

5. 通讯调参
   - 串口或 CAN 可以设置目标速度、PWM 占空比、启停状态、控制模式。

6. 状态输出

```text
target = 1000
speed = 920
duty = 45
adc = 2048
state = run
```

### 第 22-23 天：搭框架

把初始化函数拆清楚：

```c
Board_init();
GPIO_init();
SCI_init();
ADC_init();
EPWM_init();
EQEP_init();
CAN_init();
```

### 第 24-25 天：实现周期任务

例如：

```c
void controlLoopISR(void)
{
    readAdc();
    readEncoder();
    calculateSpeed();
    updatePwm();
}
```

### 第 26 天：加串口命令

支持：

```text
start
stop
duty 50
target 1000
status
```

### 第 27 天：加简单保护

比如：

- duty 限制在 0-95%
- ADC 超阈值停机
- 通讯超时停机

### 第 28 天：整理项目文档

写一个 `README.md`，内容包括：

- 项目目标
- 硬件平台
- 使用外设
- 软件结构
- 实验现象
- 后续可扩展到电机速度环、FOC、机器人关节控制

第 4 周合格标准：能拿着这个项目跟面试官讲 5-10 分钟，并且能说清楚每个模块为什么这样设计。
