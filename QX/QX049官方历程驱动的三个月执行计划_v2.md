## 二、官方例程使用原则

不要把例程当成要背诵的教材，而要把每个例程改造成一次可复现实验：

1. 原版跑通。
2. 只改一个变量。
3. 预测现象。
4. 用示波器或串口验证。
5. 保存代码、日志、波形和结论。

官方 README 中的 QX-IDE 导入、Set As Test Case、编译、烧录和晶振配置属于操作说明；真正对求职有价值的是你能解释外设时序、测量现象和异常定位。

## 四、12 周计划

### 第 0 周：环境基线

- [ ] 导入 examples_core0，记录 IDE、编译器和工程版本

验收：能独立导入、编译、烧录、复位和查看串口。

### 第 1 周：PWM 同步 ADC

例程：adc_ex1_soc_software、adc_ex2_soc_epwm。

- [ ] 记录 ADC 通道、SOC、触发源、ADCINT 和 ISR
- [ ] 只改 TBPRD，验证 PWM 与 ADC 触发频率
- [ ] 只改 CMPA，验证采样点相对 PWM 的位置
- [ ] 用示波器和 GPIO 翻转建立时序图

结论必须回答：ePWM SOCA 如何到 ADC RESULT，为什么不能只相信代码注释里的时钟假设。

### 第 2 周：多通道和过采样

例程：adc_ex10_multiple_soc_epwm、adc_ex13_soc_oversampling。

- [ ] 配置 3 至 6 个通道，记录 SOC 顺序和结果位置
- [ ] 同一输入做 4/8/16 次采样
- [ ] 计算均值、最大值、最小值、标准差
- [ ] 比较噪声改善和转换时间增加

结论必须回答：过采样降低什么噪声，牺牲什么实时性。

### 第 3 周：PPB 校准与越限

例程：adc_ex7_ppb_offset、adc_ex8_ppb_limits，阅读 adc_ex9_ppb_delay。

- [ ] 获取稳定输入基线

### 第 4 周：ePWM 时序和保护

### 第 5 周：eQEP 环回

- eQEP 如何判断方向和速度？
