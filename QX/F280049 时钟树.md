## 四种改动的影响范围

| 修改位置                             | 改变什么                | 受影响模块                               |
| -------------------------------- | ------------------- | ----------------------------------- |
| 时钟源 `SYSCTL_OSCSRC_*`            | 参考时钟来源              | 整条时钟树                               |
| `IMULT`、`IDIV`、`ODIV`、`SYSDIV`   | `SYSCLK`            | CPU、PWM、ADC、定时器、SCI、SPI 等下游模块       |
| `LSPCLK_PRESCALE`                | `LSPCLK`            | 主要是 SCI 与 SPI                       |
| `PERCLKDIVSEL.EPWMCLKDIV`        | ePWM 全局时钟 `EPWMCLK` | ePWM 的 `TBCLK`、PWM 频率、ADC ePWM 触发频率 |
| `TBCTL.HSPCLKDIV`、`TBCTL.CLKDIV` | ePWM 模块内 `TBCLK`    | 该 ePWM 的 `TBCTR` 计数速度               |
| `SysCtl_enablePeripheral()`      | 外设是否得到时钟            | 仅对应模块，频率不变                          |

## 分频与门控不是同一件事

```text
分频器：决定时钟频率，例如 100 MHz / 2 = 50 MHz。
门控：决定时钟是否送给某个外设；关闭后该外设停止工作，但其他外设频率不变。
```

例如：

```c
#define LSPCLK_PRESCALE SYSCTL_LSPCLK_PRESCALE_2
```

在当前 100 MHz 系统时钟下会得到：

```text
CPU、CPU Timer: 仍为 100 MHz
SCI、SPI 的 LSPCLK: 100 MHz -> 50 MHz
```

SCI 驱动使用 `DEVICE_LSPCLK_FREQ` 计算波特率，因此宏与真实 LSPCLK 一致时，仍可保持串口助手为 115200。

## ePWM：接口时钟、EPWMCLK 与 TBCLK

`SYSCLK = 100 MHz` 是当前工程已经确定的系统时钟；ePWM 的寄存器接口也处于该外设时钟域。但若问题是“`TBCTR` 每秒计多少次”或“ADC ePWM 触发的实际频率是多少”，还要把 ePWM 自己的两级时钟分频算进去：

```text
SYSCLK (当前 100 MHz)
-> EPWMCLK 全局分频
-> EPWMCLK
-> HSPCLKDIV、CLKDIV（每个 ePWM 的 TBCTL）
-> TBCLK
-> TBCTR 计数、CMPA 比较、SOCA/SOCB 事件
```

因此，“ePWM 连接在 SYSCLK 域”与“`TBCLK` 必然等于 100 MHz”不是同一个结论。对于具体工程，应使用：

```text
TBCLK = EPWMCLK / (HSPCLKDIV × CLKDIV)
```

本仓库的 DriverLib 注释说明复位后 `EPWMCLK` 可能为 `SYSCLK / 2`；而 `adc_ex2_soc_epwm` 的示例注释按 `EPWMCLK = 100 MHz` 来计算 50 kHz。该例程没有显式写全局 ePWM 分频，因此实际采样率要以运行时 `EPWMCLKDIV` 配置为准，不能仅从 `DEVICE_SYSCLK_FREQ = 100 MHz` 推定。

例如 `TBPRD = 1999`、向上计数、SOCA 预分频为 1 时：

```text
采样频率 Fs = TBCLK / (TBPRD + 1) = TBCLK / 2000

TBCLK = 100 MHz -> Fs = 50 kHz
TBCLK =  50 MHz -> Fs = 25 kHz
```

## 建议的验证方法

1. 在程序中读取 `SysCtl_getClock(DEVICE_OSCSRC_FREQ)`，确认运行时 SYSCLK。
2. 使用 `sci_puts_printf` 验证串口不乱码。
3. 必要时把 `XCLKOUT` 输出到 GPIO16，用示波器测量。
4. 再验证 PWM 周期、CPU Timer 和 ADC 采样率。
